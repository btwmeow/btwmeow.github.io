# Контекст проекта: Веб-сайт Военного Комиссариата ВС РО (Majestic RP)

## Описание проекта
Разрабатываем веб-сайт/портал для фракции Военный Комиссариат Вооружённых Сил (ВК ВС РО) на Majestic RP. Сайт предназначен для сотрудников фракции, содержит информацию по системе повышения, регламентам, а также интерактивные модули аттестации (тестирования).

## Дизайн и стилистика
- **Тема:** Тёмная военная / строгая фракционная эстетика.
- **Цветовая палитра:** 
  - Основной фон: тёмный (`#1e1e1e`, `#2b2b2b`).
  - Акцентный цвет: золотой/песочный (`--accent-gold: #d4af37`).
  - Текст: светлый (`#ffffff`).
- **С택 технологий:** Чистый HTML5, CSS3, JavaScript (Vanilla JS), без использования тяжелых внешних библиотек.
